# Лабораторна робота 1

Основні операції з фактами CLIPS, шаблони та правила.

Файли: `facts.txt`, `deffacts.clp`, `rule.clp`, `people.clp`,
`people_extended.clp`, `find_men.clp`, `find_women.clp`, `find_person.clp`.

Для перевірки правил пошуку завантажте спочатку `people_extended.clp`,
потім три файли `find_*.clp`, після чого виконайте `(reset)` і `(run)`.
