# Лабораторна робота 5

`lab5_prefix.clp` містить перетворення трьох арифметичних виразів у префіксну форму.

`lab5_v6.clp` містить розв'язання логічної задачі про розподіл позицій гравців (індивідуальне завдання 6). Це версія, яку було запущено в CLIPS.

Кожен файл перевіряється окремо: `(clear)`, `(load "файл.clp")`, `(reset)`, `(run)`.
