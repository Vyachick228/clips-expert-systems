# clips-expert-systems
Практичні роботи з дисципліни «Інтелектуальні інформаційні технології».

# Експертні системи на базі CLIPS
Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Структура репозиторію
- `Lab1/` - операції з фактами, шаблони та правила: `facts.txt`, `deffacts.clp`, `rule.clp`, `people.clp`, `people_extended.clp`, `find_men.clp`, `find_women.clp`, `find_person.clp`, `README.md`.
- `Lab2/` - представлення родинних зв'язків і дерева рішень: `lab2.clp`, `lab2_v6.clp`, `README.md`.
- `Lab3/` - правила для опису родини та підбору чагарників: `lab3.clp`, `lab3_v6.clp`, `README.md`.
- `Lab4/` - функції для підбору чагарників: `lab4_v6.clp`, `README.md`.
- `Lab5/` - префіксні вирази та логічна задача про бейсбольну команду: `lab5_prefix.clp`, `lab5_v6.clp`, `README.md`.
- `README.md` - опис навчального проєкту.

## Висновки
Під час виконання лабораторної роботи я ознайомився з GitHub та навчився організовувати файли CLIPS у репозиторії. Для кожної лабораторної роботи було створено окрему папку, а код і результати попередніх робіт упорядковано. Також я навчився оформлювати README.md і зберігати зміни за допомогою комітів.
